## FAQ - Managed CMS Hosting

**Q: What does "managed" actually mean?**  
A: We handle all server management, CMS updates, security patches, performance optimization, and technical troubleshooting. You focus on content/sales, we handle the technical details.

**Q: Will you update my plugins/themes automatically?**  
A: WordPress: We test on staging first, then apply (with rollback option). Magento: Updates are tested and applied during maintenance windows. You can choose manual approval if preferred.

**Q: What if an update breaks my site?**  
A: We test on staging first. If it breaks there, we don't apply it to production and notify you. If something breaks on production (rare), we rollback immediately to working version.

**Q: Can I still install plugins/themes myself?**  
A: Yes, you have full access to your CMS admin panel. We just monitor for conflicts and security issues.

**Q: Do I get root/SSH access?**  
A: WordPress Solo: No (cPanel/SFTP only). Professional+: SSH access available. Magento: SSH included on all plans.

**Q: How do backups work?**  
A: Automated daily backups (hourly on higher plans). Retained 30-90 days depending on plan. One-click restore through dashboard. Backups stored off-server.

**Q: What's included in "free migration"?**  
A: Complete site migration including files, database, configurations, testing, and DNS cutover. Usually 1-7 business days. We handle everything.

**Q: Can you optimize my existing site?**  
A: Yes, optimization is included in managed hosting. We'll audit and optimize after migration. Ongoing optimization happens automatically.

**Q: What about email hosting?**  
A: Email included with WordPress plans. For Magento/other CMS, recommend separate email service (Gsuite, Office 365) for reliability.

**Q: Do you support WooCommerce?**  
A: Yes, WooCommerce is fully supported on WordPress plans. Optimized for e-commerce performance and security.

**Q: What about WordPress Multisite?**  
A: Supported on Professional and Enterprise plans. Requires manual approval during signup for resource planning.

**Q: Can I use my own CDN?**  
A: Yes, you can use any CDN. We include CDN on Professional+ plans (optional to use ours or yours).

**Q: What's your refund policy?**  
A: 30-day money-back guarantee. After 30 days, cancel anytime with prorated refund for unused time.

**Q: Do you support custom themes/plugins?**  
A: Yes. We'll check for conflicts and compatibility issues. If custom code causes issues, we'll help troubleshoot but can't fix bugs in your custom code.

**Q: What about staging environments?**  
A: Included on all managed plans. One-click staging creation, test changes safely, then push to production.

**Q: How many backups do you keep?**  
A: Solo/Starter: 30 days. Professional: 60 days. Enterprise: 90 days. Additional retention available on request.
