## What is Dedicated Server Hosting?

### Physical Servers, Not Virtual

A dedicated server is an entire physical machine reserved exclusively for your use. Unlike VPS (virtualized) or cloud (distributed), you get:

**Complete Hardware Access**
- Entire CPU (all cores, no sharing)
- All RAM (no hypervisor overhead)
- All storage bandwidth
- Dedicated network interface
- IPMI/iDRAC for remote management

**Maximum Performance**
- No "noisy neighbor" effects (it's all yours)
- No virtualization overhead (~5-10% performance cost)
- Predictable, consistent performance
- Maximum I/O throughput
- Lowest possible latency

**Physical Isolation**
- Complete security isolation
- No hypervisor vulnerabilities
- Compliance requirements (HIPAA, PCI, etc.)
- Custom hardware possible
- Physical security controls

**Flexibility**
- Custom RAID configurations
- Any operating system (even custom)
- Custom kernel modules
- Specialized hardware (GPUs, etc.)
- Whatever you can run on bare metal

## When to Choose Dedicated Servers

### Upgrade to Dedicated When:

✓ **VPS resources aren't enough** for your application  
✓ **Maximum performance is critical** to your business  
✓ **Compliance requires physical isolation** (HIPAA, PCI DSS, etc.)  
✓ **You need consistent high-I/O performance** (databases, file servers)  
✓ **Security requires physical separation** from other tenants  
✓ **Custom hardware needed** (specific CPUs, GPUs, storage configs)  
✓ **Licensing requires physical servers** (some enterprise software)  
✓ **You're running resource-intensive workloads** continuously  

### Stick with VPS/Cloud If:

✗ Your workload works fine on VPS  
✗ You need instant scalability (VPS/cloud scales faster)  
✗ Budget is tight (VPS is more economical for smaller workloads)  
✗ You don't need maximum single-server performance

### Memory Configurations

**DDR4 ECC RAM:**
- 32GB: Minimum for dedicated servers
- 64GB: Good for most applications
- 128GB: Databases, caching, VMs
- 256GB: Large databases, many VMs
- 512GB+: Big data, in-memory databases

**ECC vs Non-ECC:**
- ECC (Error Correcting Code): Detects and fixes memory errors
- Required for data integrity in production
- All managed servers include ECC
- Unmanaged: ECC available on request

---

### Storage Configurations

**NVMe SSD (Recommended):**
- Fastest storage option (3,000-7,000 MB/s)
- Low latency (<100µs)
- Best for databases, high-I/O applications
- Available in RAID-0, RAID-1, RAID-10

**SATA SSD:**
- Good performance (500-600 MB/s)
- More economical
- Suitable for most workloads
- Higher capacities available

**SATA HDD:**
- Economical bulk storage
- Good for archives, backups, media
- 4-20TB per drive
- Not recommended for primary storage

**RAID Configurations:**
- **RAID-0:** Maximum speed, no redundancy (not recommended)
- **RAID-1:** Mirror (2 drives), redundancy
- **RAID-5:** Parity (3+ drives), space efficient
- **RAID-10:** Mirror + Stripe (4+ drives), best performance + redundancy

## FAQ - Dedicated Servers

**Q: What's the difference between dedicated and VPS?**  
A: Dedicated is an entire physical server. VPS is a virtual partition of a physical server. Dedicated gives you all resources, no virtualization overhead, and better isolation. VPS is more economical for smaller workloads.

**Q: How long does server delivery take?**  
A: In-stock configurations: 2-6 hours. Custom configurations: 3-14 business days depending on hardware availability.

**Q: Can I upgrade my server later?**  
A: Yes. RAM and storage can be added. CPU upgrades require server replacement (we can migrate your data).

**Q: Do I get root access?**  
A: Yes, full root/administrator access on all dedicated servers.

**Q: What operating systems are available?**  
A: Linux: Ubuntu, Debian, CentOS, AlmaLinux, Rocky Linux, Fedora. Windows Server: 2019, 2022 (licensing additional). Custom OS via IPMI.

**Q: Is Windows Server included?**  
A: No, Windows Server licensing is additional ($20-60/month depending on edition).

**Q: What about backups?**  
A: Managed plans include automated off-site backups. Unmanaged plans can add backup service or handle their own backups.

**Q: What's your uptime guarantee?**  
A: 99.9% for unmanaged. 99.95-99.99% for managed plans depending on tier. Network uptime typically exceeds 99.99%.

**Q: Can I get remote hands if needed?**  
A: Yes, $100/hour for technician to physically interact with your server. Included in emergency hardware replacement.

**Q: What if hardware fails?**  
A: We replace faulty hardware within 4-24 hours depending on plan. RAID redundancy protects your data during drive failures.

**Q: Can I host multiple domains/sites?**  
A: Yes, unlimited. It's your server, use it however you want.

**Q: Do you provide DDoS protection?**  
A: Yes, 10Gbps DDoS mitigation included. Larger attacks (100Gbps+) available for additional cost.

**Q: Can I install any software?**  
A: Yes, you have root access. Install whatever you want (legal uses only).

**Q: What about bandwidth limits?**  
A: Unmetered means no caps. Use what you need for legitimate traffic. We only intervene for network abuse.

**Q: How do I access my server if it's down?**  
A: IPMI/iDRAC provides out-of-band access. You can access the console, mount ISOs, and power cycle remotely even if OS is unresponsive.

**Q: Can I get a custom configuration?**  
A: Yes, contact sales. We can source specific CPUs, RAM configurations, GPU servers, or specialized hardware.

**Q: What's your refund policy?**  
A: 30-day money-back guarantee (minus setup fees if any). After 30 days, cancel with 30 days notice, prorated refund.
