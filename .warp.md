## Project Overview
**Qpanda** is a dual-purpose platform built with Next.js, featuring a quantum-themed public hosting site with an integrated premium client portal. The design follows Spaceship.com-inspired fluid UI patterns and modern SaaS aesthetics.

### Architecture Overview
- **Public Site (/)**: Quantum-themed landing page with hosting plans, features, and marketing content
- **Client Portal (/clientarea)**: Premium dashboard for existing customers - invoices, tickets, services, account management
- **Unified Navigation**: Seamless transition between public site and authenticated client area
- **Shared Design System**: Consistent quantum/panda theme across both sections
- **Backend**: Cloudflare Workers, D1, R2, KV integration for both public and client features

---

## Technical Architecture

### Frontend Stack
- **Framework**: Next.js 14+ with App Router
- **Deployment**: Cloudflare Pages
- **Styling**: Tailwind CSS with custom design tokens
- **State Management**: React hooks with context patterns
- **Animations**: Framer Motion + View Transitions API

### Backend Infrastructure
- **API Layer**: Cloudflare Workers at `api.qpanda.cloud`
- **Database**: Cloudflare D1 for cached data
- **Storage**: R2 for attachments (up to 25MB)
- **Sessions**: KV store for JWT sessions
- **Integration**: WHMCS connector via CF Tunnel

### Security & Performance
- **Authentication**: JWT sessions with HMAC signing
- **Security**: CSRF protection, rate limiting, IP allowlists
- **Performance Targets**:
  - TTFB < 300ms (cached)
  - LCP < 2.0s on 4G
  - Lighthouse Performance ≥ 95
  - INP < 200ms on mid-range devices

## API Contracts & Data Flow

### Core API Endpoints
```typescript
// Invoice Management
GET /api/invoices -> Invoice[]
POST /api/invoices/:id/pay -> { status: 'redirect', url: string }

// Ticket System
GET /api/tickets -> Ticket[]
POST /api/tickets -> { id: string, message: string, attachments: File[] }
GET /api/tickets/:id -> TicketThread

// Service Management
GET /api/services -> Service[]
GET /api/services/:id -> ServiceDetails

// User Management
GET /api/user -> UserProfile
PUT /api/user -> UpdatedUserProfile
```

### WHMCS Integration
- Connector app on WHMCS host
- CF Tunnel for secure API bridge
- HMAC-signed requests for security
- Real-time sync of invoice/ticket status
