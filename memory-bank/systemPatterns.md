# System Patterns
- Framework: Next.js (app directory) with React Server/Client components mix.
- Styling: Tailwind utility classes with occasional gradients/glow; framer-motion for subtle motion.
- Components: Shared luminous card shell in `app/components/LuminousCard.tsx`; mega menu and hero in `QPandaOnePager.jsx`; hosting landing cards in `app/hosting/page.tsx`.
- Testing: Playwright smoke (`tests/demo.spec.ts`) for nav/menu flow and screenshots.
